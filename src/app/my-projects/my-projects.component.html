✨ CRUD de Pokémon feito em Laravel e Tailwind 🚀

💡 O que foi feito:


  • Back-end: Laravel estruturando a aplicação, além do uso do Eloquent ORM para conectar os dados de Pokémon e Treinadores. O Breeze foi utilizado para validação e controle de cadastro e login de usuários.
  • Front-end: Utilizei o Blade para estruturar o Front de forma dinâmica, aliado ao Tailwind CSS, para poder estilizar as páginas de forma simples e moderna.
  • Funcionalidades: CRUD completo (Create, Read, Update, Delete), registro e login de usuários e exclusão de usuários cadastrados.
  • Documentação: O projeto no GitHub está disponível em português e inglês, com documentação detalhada sobre requisitos, instalação e uso.
